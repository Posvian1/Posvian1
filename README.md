# Портфолио: Data Science & Product Analytics

Добро пожаловать! Здесь собраны мои учебные и практические проекты, демонстрирующие навыки в области анализа данных, прогнозирования и построения моделей. Каждый проект находится в отдельной папке и содержит код, выводы и визуализации.

## 🧰 Стек технологий
- **Python** (pandas, numpy, matplotlib, seaborn, scikit-learn)
- **Модели:** LinearRegression, RandomForest, LightGBM, CatBoost, LogisticRegression, DecisionTree, KNeighbors
- **Инструменты:** Jupyter Notebook, Git, Bootstrap, A/B-тестирование
