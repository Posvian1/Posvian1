# Портфолио: Data Science & Product Analytics

Добро пожаловать в мое портфолио! Здесь собраны проекты, демонстрирующие мои навыки в области анализа данных, прогнозирования и построения моделей машинного обучения для решения бизнес-задач.

## 🧰 Ключевые навыки и инструменты

*   **Языки:** Python (Pandas, NumPy, Scikit-learn)
*   **Модели:** LinearRegression, RandomForest, LightGBM, CatBoost, LogisticRegression, DecisionTree, KNeighbors
*   **Основные области:** Регрессия, Классификация, Кластеризация, Анализ временных рядов, A/B-тестирование, Bootstrap
*   **Специализация:** Продуктовая аналитика, Прогнозирование, Оценка рисков
